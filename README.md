# illumina-run-dirs

This project contains scripts used for working with Illumina sequencer run data, including HiSeq 2000/2500, MiSeqs, NextSeqs 550 and 2000, Novaseq 6000 and X Plus.

* [Check and Clean](check-and-clean) : contains scripts for cleaning run directories once data has been generated
